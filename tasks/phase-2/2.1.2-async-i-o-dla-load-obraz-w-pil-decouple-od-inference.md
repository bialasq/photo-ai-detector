   async def load_worker(paths: list[Path], queue: asyncio.Queue):
     for p in paths:
       img = await asyncio.to_thread(load_image, p)
       await queue.put((p, img))
     await queue.put(None)  # sentinel
   
   async def inference_worker(queue, results):
     while True:
       item = await queue.get()
       if item is None: break
       p, img = item
       faces = await asyncio.to_thread(detect_faces, img)
       results.append((p, faces))
2. Queue maxsize=64 (back-pressure jeśli inference wolniejsze niż load).
3. Cancellation: state.cancelled → cancel obu tasków + drain queue.
