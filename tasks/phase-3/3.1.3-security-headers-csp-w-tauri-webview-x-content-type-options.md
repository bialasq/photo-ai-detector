ROLA: Senior security + Tauri engineer.

TASK: Security headers backend + Tauri CSP.

WYMAGANIA:
1. main.py middleware add security headers:
   @app.middleware('http')
   async def security_headers(request, call_next):
     response = await call_next(request)
     response.headers['X-Content-Type-Options'] = 'nosniff'
     response.headers['X-Frame-Options'] = 'DENY'
     response.headers['Referrer-Policy'] = 'no-referrer'
     return response
2. tauri.conf.json CSP:
   'security': { 'csp': "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: http://127.0.0.1:8000; connect-src 'self' http://127.0.0.1:8000" }
3. Verify dev mode app działa po CSP (Tauri devtools może pomóc).

ACCEPTANCE: 1 pytest + manual smoke (app działa po CSP).

DELIVERABLE: diff + test.
