## Meta — jak używać tego pliku

Sześć promptów do Cursor agent mode, **sekwencyjnie**. Każdy = osobna sesja Cursora = jeden commit. Między sesjami: **human gate** (Ty czytasz output, robisz `git diff`, decydujesz "go / refine / abort").

**Czemu sekwencja a nie jeden mega-prompt?**
1. Cursor agent w jednej sesji ma ograniczone okno kontekstu — duża zmiana = halucynacje przy edytowaniu plików.
2. Małe commity → łatwy rollback jeśli któryś krok zepsuje testy.
3. Gates pozwalają Ci wyłapać scope creep zanim się rozleje.

**Czas:** ~5–7 sesji × 30–90 min = 4–8h kalendarzowych. Nie próbuj zrobić tego za jednym posiedzeniem.
