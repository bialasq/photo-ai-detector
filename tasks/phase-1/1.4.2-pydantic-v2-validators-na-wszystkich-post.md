## Acceptance Criteria

- [ ] Wszystkie POST body to BaseModel z field constraints
- [ ] Path validation (Field(min_length=1, max_length=4096))
- [ ] Person name (Field(min_length=1, max_length=200, pattern=r'^[\w\s\-\.]+$'))
- [ ] Cluster IDs (Field(ge=1))
- [ ] 10 pytest: każdy endpoint × 1 invalid case → 422
- [ ] Frontend ErrorBoundary radzi sobie z 422 (z 1.1.4)
